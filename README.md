# STORYMATE STUDIO V0.7.1 – Experimental

Mobile-first PWA for story development and AI film production workflows.

## V0.7.1 updates
- Character Bible with a canonical Permanent Character DNA profile.
- Separate reusable variations: Costume, Expression, Story Age, and Physical Condition.
- Character Bible summary and variation management.
- Asset Library supports linking an asset to a character and project.
- Asset add/edit, image replacement, category filtering, search, download, and delete.
- IndexedDB persistence and JSON backup/restore retained.

## Deploy
Upload the contents of this folder to the repository root, then enable GitHub Pages from `main` / root.

## Data
Data is stored locally in the browser using IndexedDB. It is not cloud-synced. Export JSON backups regularly. Do not remove older working versions until the new version has been tested.
